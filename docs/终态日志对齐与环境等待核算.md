## 第二部分：环境等待核算

### 5. 定义

- **模型时间**：工具结果或输入返回后，到下一条 assistant 记录产生为止，包含 API 延迟、思考与生成。
- **工具时间**：前台工具调用从发起到返回。
- **等待**：既不在生成、也不在执行前台工具的时间，即主会话在等后台任务或子代理。
- **环境等待**：由运行环境或任务规则决定、不能靠推理缩短的时长：固定时长的实玩、下载与安装、构建与测试的执行、轮询等待，以及环境问题引起的额外测试。

### 10. 口径限制

- 模型时间是用相邻记录的时间差估算的，包含 API 排队与网络延迟，无法与纯生成时间分开。
- 子代理按各自的区间并集计时；它们并行运行，所以合计会超过墙钟。
- 实玩的驾驶会话在实玩的固定时长之内，不单独核算。
